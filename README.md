# Website Design Constraints

## Overview

This project is a mockup design for a client-side banking  website. Design it in HTML and CSS, focus solely on designing and do not add any funtionality 


This website should present a professional, modern, and technically oriented appearance. The visual design must prioritize readability, consistency, and content clarity over decorative elements.

---

# Design Philosophy

* Clean and minimal interface.
* Professional rather than playful.
* Avoid excessive visual effects.
* Maintain consistency across all pages.

---

# Color Constraints

## General Principles

* Use a light theme as the primary design.
* Avoid highly saturated colors.
* Avoid dominant red, orange, pink, or neon accents.
* Use charcoal, slate, and neutral gray tones.
* Accent colors should be subtle and professional.

# Layout Constraints

## Width

* Maximum content width: 1200px
* Content centered horizontally.

## Spacing

Use an 8px spacing system:

* 8px
* 16px
* 24px
* 32px
* 48px
* 64px

Avoid arbitrary spacing values.

---

# Navigation Constraints

* Navigation bar must remain simple.
* Maximum 6 primary navigation items.
* Logo positioned on the left.
* Navigation items aligned to the right.
* No animated navigation effects beyond subtle hover transitions.

---

# Component Constraints

## Buttons

### Primary Button

* Background: #334155
* Text: White
* Border Radius: 8px

### Secondary Button

* White background
* Gray border
* Dark text

## Cards

* White background
* Light border
* Border radius: 12px
* Soft shadow only

Avoid heavy shadows.

---

# Icon Constraints

* Use outline or minimalist icons.
* Maintain a consistent icon family.
* Use monochrome icon colors.
* Default icon color: #475569

---

# Animation Constraints

Allowed:

* Hover transitions
* Fade-in effects
* Smooth scrolling

Not Allowed:

* Excessive motion
* Auto-playing animations
* Flashing effects
* Parallax effects
* Attention-grabbing visual gimmicks

Animation duration:

* 150ms–300ms

---

# Accessibility Constraints

* Maintain sufficient color contrast.
* Text must remain readable at 200% zoom.
* Interactive elements must have visible focus states.
* Do not rely solely on color to communicate information.

---

# Responsive Design Constraints


## Desktop

* Default width and height should be (800, 600)
